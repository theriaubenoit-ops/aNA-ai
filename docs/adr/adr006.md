## 🏛️ ADR 006: Mécanisme de Sélection NMDA _(Magnesium Block) (aNA AI Project v5.3b)_

**Date:** April 19, 2026
**Status:** Validated / Implemented

**Decision-makers:** Benoit Theriault & Gemini _(aNA Core Team)_

![ ](/docs/assets/spacer32x32.png)

### Context

**aNA** AI v5.2b suffered from memory saturation _(too much volatile information stored unnecessarily)_.

![ ](/docs/assets/spacer16x16.png)

### Décision

Implementation of a _binary filter_ based on _NMDA_ receivers.

Volatile Phase _(AMPA)_: Temporary recording.

Burning Phase _(NMDA)_: Requires a threshold of 0.65 _(Signal + Attention)_.

![ ](/docs/assets/spacer16x16.png)

### Consequence

The seahorse becomes _"skeptical."_ It ignores _background noise_ and only consolidates _salient patterns_.
